JJS CARGO - WEBSITE MULTI-PAGE

Isi folder:
- index.html: Beranda
- tentangkami.html: Tentang Kami
- layanan.html: Layanan
- kontak.html: Kontak
- style.css: Desain bersama untuk semua halaman
- script.js: Menu mobile, menu aktif, tahun footer

CARA MENJALANKAN
1. Ekstrak ZIP ke folder pilihan Anda.
2. Buka VS Code. Pilih File > Open Folder, lalu pilih folder jjs-cargo-website-multipage.
3. Buka index.html.
4. Cara termudah: pasang ekstensi Live Server di VS Code, klik kanan index.html, lalu pilih Open with Live Server.
   Alternatif: klik dua kali index.html untuk membuka langsung di browser.
5. Gunakan menu navigasi untuk berpindah antarhalaman.

CATATAN PENTING
- Desain menggunakan Google Fonts, Font Awesome, dan foto Unsplash melalui internet.
- Semua alamat, email, nomor telepon, klaim operasional, daftar layanan, statistik, dan rincian cabang harus diverifikasi dan diganti dengan data resmi JJS sebelum website dipublikasikan.
- Fitur cek resi dan kalkulator tarif dari kode awal tidak disertakan sebagai fungsi aktif, karena contoh tersebut hanya simulasi dan belum terhubung ke database/sistem TMS. Jangan tampilkan hasil simulasi sebagai data pengiriman atau tarif nyata.
- Pastikan manajemen menyetujui konten, penggunaan foto, domain, dan kontak sebelum publikasi.
